做趁手的工具。

上海交通大学在读。这里放我做的几个小工具——两个围绕「读论文」这件事：一个帮你查清前人做过什么，一个陪你把论文亲手做一遍。

其一主要作品

问渠QIANREN

一句话，查清前人做过什么、还空着什么。

输入一个研究想法或问题，并行检索 OpenAlex、Semantic Scholar、Crossref、Europe PMC、DBLP、arXiv 六大学术来源，去重合并后逐篇抽取关键字段，生成「方法 × 年份」全景、论文卡片与研究空白点，可导出 Markdown / CSV / BibTeX。2026 Qoder 高校创造力大赛 StudyHack 学习科研赛道参赛作品。

论文检索对比矩阵纯静态 + 边缘函数免 key 可用
在线体验 详细介绍 GitHub 仓库

琢玉ZHUOYU

问渠回答「前人做过吗」，琢玉回答「我怎么亲手做一遍」。

本地优先的论文复现学习工作台：把一篇论文拆成可上手的复现卡片，顺着「拆解 → 知识地图 → 复现计划 → 记事本 → 指标对照 → 导出 → 技能树」七步主线，一步步把论文做出来。数据只留在浏览器本地，无后端、无账号。TRAE 参赛作品。
